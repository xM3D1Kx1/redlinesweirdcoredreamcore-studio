# DREZZDON Studio — как открыть сайт «только для себя»

Никаких Cloudflare, Render и деплоя. Сайт живёт на вашем компьютере:
запустили — смотрите, правите файл — видите изменения сразу.

---

## 1. Один раз вставьте ключ Gemini

1. Откройте https://aistudio.google.com/apikey → **Create API key** → скопируйте ключ
   (выглядит как `AIzaSy...`).
2. Откройте файл **`.env`** в этой папке (Блокнот подойдёт).
3. Замените строку `GEMINI_API_KEY=PASTE_YOUR_KEY` на свою:

```
GEMINI_API_KEY=AIzaSy...
```

4. Сохраните. Больше ничего делать не нужно.

Ключ остаётся на компьютере: в браузер он не попадает, в код страницы не вшит.
Файл `.env` никому не пересылайте — это как пароль.

Без ключа сайт открывается, но разметку не нарисует: в статус-строке появится
понятная ошибка. Ключ нужен обязательно.

---

## 2. Запуск (2 клика)

1. Двойной клик по **`Запустить сайт.cmd`** (или по ярлыку на рабочем столе).
2. Откроется чёрное окно с адресом и сразу браузер.
3. В окне будет строка `Gemini: ключ найден ✓  модель gemini-3.6-flash (запасные: …)`
   — значит всё готово. Окно **не закрывайте**, пока работаете.

Адрес: **http://localhost:8080**

## 3. Как пользоваться

1. **ЗАГРУЗИТЬ ФОТО** (или перетащите картинку в окно) — анализ запустится сам.
2. Справа по шагам идёт конвейер: анализ сцены → подписи → отрисовка.
   Через 10–40 секунд на фото появляется красная разметка, а под ней в списке —
   что именно нашла модель (тип, уверенность, подпись).
3. Клик по элементу в списке подсвечивает рамку. Рамку можно тащить мышкой,
   двойной клик по подписи — изменить текст.
4. **Сохранить** — PNG с разметкой уходит в «Загрузки».
5. **Переделать оформление** — новый вариант разметки того же фото
   (счётчик «Вариант» растёт). Каждое нажатие = один запрос к Gemini.
6. **Следующее фото** — выбор новой картинки.

Кнопка **Показать оригинал** убирает разметку, чтобы сравнить с исходником.

Ещё две вещи, которые уже работают:

- **Язык подписей** — переключатель `EN / DREZZDON` ↔ `RU / РУССКИЙ` в шапке.
  Выбор запоминается и применяется при следующей разметке.
- **Последнее фото помнится** на устройстве: закрыли сайт, открыли снова — фото
  на месте, остаётся нажать «Переделать оформление». На телефоне и на ПК память
  своя, в сеть фото не уходит.

Старый холст-редактор никуда не делся — ссылка **«Старый редактор»** в шапке
(`pwa\drezzdon_studio.html`): там ручные инструменты, стили и таскание рамок
без обращения к Gemini.

## 4. Как обновлять сайт

1. Откройте `pwa\drezzdon_studio.html` (или `pwa\ai.js`) в редакторе.
2. Меняйте что угодно.
3. **Ctrl + S** → вкладка в браузере перезагрузится сама через секунду.
   Если нет — F5.

Чтобы обновление увидел телефон — просто обновите страницу на нём.

## 5. С телефона и с ПК одновременно

Сервер один, а открывать его можно с любого устройства — и с компьютера, и с
телефона. Они не мешают друг другу; у каждого свой холст.

**Телефон дома (та же Wi-Fi):**

1. В чёрном окне найдите строку `С телефона (Wi-Fi): http://192.168.x.x:8080`.
2. Введите этот адрес в браузере телефона (Chrome/Safari).
3. Первый запуск: Windows спросит про доступ к сети — разрешите **«Частные сети»**.
   Если окно не появилось, а телефон не открывает — Брандмауэр Защитника Windows →
   «Разрешить приложение» → Node.js → поставить галочку «Частная».

На телефоне интерфейс уже подстроен: шапка в две строки, панель инструментов
прокручивается вбок пальцем, холст занимает всю ширину, рамки тащатся пальцем,
двойной тап по подписи — править текст.

Ярлык: меню браузера → «Добавить на главный экран» — будет как приложение,
запускается в полный экран.

**Телефон вне дома (мобильный интернет, кафе, работа):**

Нужен приватный канал до вашего ПК. Самый простой — **Tailscale** (бесплатно,
без настройки серверов):

1. Поставьте Tailscale на ПК: https://tailscale.com/download/windows → войдите.
2. Поставьте приложение Tailscale на телефон (Google Play / App Store) → тот же аккаунт.
3. На ПК запустите сайт как обычно.
4. На телефоне откройте `http://<tailscale-имя-пк>:8080` — например
   `http://desktop-abc123:8080` (имя ПК видно в админке Tailscale).

Это личная сеть: снаружи сайт не виден никому, кроме ваших устройств.

> Публичный адрес (Cloudflare Tunnel и подобное) тоже возможен одной командой, но
> тогда сайт виден в интернете — в этом случае запускайте с паролем:
> `set SITE_PASSWORD=мойпароль && node serve.js`

## 6. Остановить

Ctrl + C в чёрном окне или просто закройте его.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| «Gemini не ответил (… 400 …)» | ключ неверный или скопирован с пробелом — перепроверьте `.env` |
| «Лимит запросов исчерпан» | квота на сегодня кончилась, подождите или смените ключ |
| «Все модели заняты (503)» | у Google перегрузка; сервер сам перебирает запасные, просто нажмите «Переделать оформление» через минуту |
| «Модель не найдена (404)» | Google закрыл модель — впишите актуальную в `GEMINI_MODELS` (`.env`), список: `…/v1beta/models?key=…` |
| Ответ идёт 20–40 секунд | нормально для «умного» анализа фото, подождите |
| «GEMINI_API_KEY не задан» | ключ не сохранился в `.env`, или сервер запущен до правки — перезапустите |
| «Node.js не найден» | установите LTS с https://nodejs.org |
| Порт занят | сервер сам возьмёт 8081, 8082… смотрите адрес в окне |
| Старый вид страницы | Ctrl + F5 |
| Телефон не открывает | тот же Wi-Fi + разрешить Node.js в брандмауэре (частные сети) |

## Файлы

| Файл | Что это |
|---|---|
| `pwa\index.html` | новый экран-студия: шапка, статус, конвейер, список элементов |
| `pwa\styles.css` | оформление студии |
| `pwa\app.js` | логика студии: запрос к Gemini, разбор, отрисовка, перетаскивание |
| `pwa\drezzdon_studio.html`, `pwa\ai.js` | старый холст-редактор (ссылка «Старый редактор») |
| `serve.js` | локальный сервер + прокси к Gemini (без зависимостей) |
| `.env` | здесь лежит ключ |
| `Запустить сайт.cmd` | двойной клик для запуска |
| `backend_nodejs\`, `backend_python\` | старые отдельные бэкенды, для этого запуска не нужны |

## Для отладки (необязательно)

- `http://localhost:8080/api/health` — виден ли ключ серверу.
- Запуск без ключа, на тестовом ответе: `set MOCK=1 && node serve.js`
  (рисует заглушку — удобно проверять вёрстку, не тратя квоту).
