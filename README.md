# DREZZDON AI Vision Studio v2.0 (Android PWA + Cloudflare Pages & Workers + Node/Python Backend)

## ▶ Локальный запуск (для личного использования, без хостинга)

1. Вставьте ключ Gemini в файл `.env` (строка `GEMINI_API_KEY=`).
2. Двойной клик по `Запустить сайт.cmd`.
3. Откроется `http://localhost:8080` — загрузите фото и нажмите
   «⚡ Авто-генерация (Умный анализ)».

Подробно: [КАК-ПОЛЬЗОВАТЬСЯ.md](КАК-ПОЛЬЗОВАТЬСЯ.md).

Полноценное работающее приложение для автоматического ИИ-анализа фотографий и построения красной графической разметки в стиле **DREZZDON** (по одной фотографии за раз, без ручных промптов).

## Что нового в версии 2.0 (по результатам вашего теста на Cloudflare)
1. **Исправлен выход заголовков за правый край кадра**: в модуле планирования (Этап 2) и векторного рендеринга (Этап 3) добавлен динамический замер ширины текста (`ctx.measureText`) и жёсткое удержание координат заголовка внутри безопасной рамки кадра.
2. **Устранены повторяющиеся подписи**: каждая деталь на фотографии получает уникальную по смыслу подпись без дублирования (`point of tension` / `static detail` больше не повторяются).
3. **8 встроенных сцен и расширенный классификатор**:
   - `1. Небо и светофор` (Эталон №1)
   - `2. Силуэт и парапет` (Эталон №2)
   - `3. Автомобиль ночью` (Купе под натриевым фонарём)
   - `4. Архитектура и кот` (Бруталистский балкон и горное озеро)
   - `5. Грозовое поле и дом` (**Ваша фотография с гравийной дорогой, белым домом и опорами ЛЭП!**)
   - `6. Неон и переход` (Ночной город после дождя, велосипед и витрина)
   - `7. Ретро-ЭЛТ и камера` (Терминал, плёночная камера 35мм, кружка и лампа)

4. **Нативная поддержка Cloudflare Pages + Functions**:
   - В папке `cloudflare_pages/` лежат готовый `index.html`, `functions/api/analyze.js` и `wrangler.toml`.
   - При загрузке в Cloudflare Pages приложение автоматически обращается к `/api/analyze` на том же домене (если задан `GEMINI_API_KEY` в переменных окружения Cloudflare), а при работе без ключа мгновенно использует встроенный локальный движок компьютерного зрения (On-Device CV + TensorFlow.js).

## Быстрый деплой в Cloudflare Pages
1. Зайдите в панель **Cloudflare Dashboard → Compute (Workers & Pages) → Create → Pages → Direct Upload** (или подключите Git-репозиторий с содержимым папки `cloudflare_pages/`).
2. Загрузите папку `cloudflare_pages/`.
3. *(Опционально для облачного Gemini 2.5 Flash)*: перейдите в **Settings → Environment variables** вашего проекта Cloudflare Pages и добавьте переменную `GEMINI_API_KEY` со значением вашего ключа Google AI Studio.
4. Откройте полученную ссылку `https://*.pages.dev` на смартфоне Android и нажмите **«Добавить на главный экран»** для установки как PWA-приложения!
